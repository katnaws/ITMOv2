## Question

Как запустить тесты? Укажи файл-источник.

## Answer

Чтобы запустить тесты, выполните команду из Makefile в папке `lab/demo`:

```bash
make test
```

Это вызывает команды из файла `demo/Makefile` (строка 2–3), которая запускаетunittest с параметром `-v` через Python.

Или прямо в терминале:

```bash
python3 -m unittest -v
```
