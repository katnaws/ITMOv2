## Question

Сохраняются ли подписки после перезапуска процесса? Подтверди кодом.

## Answer

Нет, подписки **не сохраняются** после перезапуска процесса.

Это подтверждается кодом:

1.  В файле `demo/service.py` (строка 1) переменная `subscribers = set()` объявлена **без имени класса**. Это означает, что она существует только в память текущего процесса при его запуске.

2.  В файле `demo/test_service.py` (строка 7) используется метод `subscribers.clear()` внутри теста `setUp`, что также предполагает, что набор переписывается при каждом запуске теста.

Python не имеет встроенного механизма сохранения данных между запусками скриптов без использования внешних средств (файлов, баз данных и т.д.). Здесь данные хранятся только в оперативной памяти.
