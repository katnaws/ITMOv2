OpenSpec: proposal → specs → design → tasks → apply → validate → archive с синхронизацией основной спецификации. Spec Kit: constitution → specify/clarify → plan → tasks → analyze → implement → converge по сгенерированным агентным инструкциям и официальным скриптам. Это не заявление об автоматическом запуске единой CLI-команды для всех стадий.

[Руководство к защите](DEFENSE_GUIDE.md) содержит речь, карту файлов и вопросы. [WORKFLOW](frameworks/WORKFLOW.md) фиксирует реальные команды, участников и ограничения. Архив OpenSpec — артефакт жизненного цикла спецификации; Git-коммиты и push не создавались. Персональные задания в проверках не использовались.
