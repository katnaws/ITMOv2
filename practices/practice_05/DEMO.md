# Демонстрация переноса дедлайна

Все команды ниже запускаются из корня репозитория.

## Запуск

Сейчас доступно http://127.0.0.1:8765/?mode=demo. Если приложение уже открывается, второй сервер не нужен.

```sh
npm --prefix practices/practice_04/dashboard run build
python3 practices/practice_05/frameworks/tests/demo_server.py --port 8765 --meta /tmp/practice05-demo.json
```

Помощник создаёт отдельные временные SQLite для real и demo, выводит URL и пути и удаляет базы при завершении. Если порт занят, используйте `--port 0`: фактический URL появится в указанном JSON. Остановка своего процесса — Ctrl+C. Обычный `dashboard/server.py` в режиме real использует постоянную базу, поэтому для репетиции удобнее помощник.

При отсутствии зависимостей установите их с рабочей директорией dashboard. Из корня:

```sh
python3 -c 'import subprocess; subprocess.run(["npm", "ci", "--ignore-scripts", "--no-audit", "--no-fund"], cwd="practices/practice_04/dashboard", check=True)'
```

## Показ за 5–7 минут

1. Объясните фичу: меняем дату существующего задания, остальные поля сохраняются.
2. Покажите [сравнение](frameworks/COMPARISON.md), две [спецификации](frameworks/README.md) и [контракт](frameworks/contract.yaml). Они подготовлены до нового прогона реализации на исходной версии без этой фичи.
3. Откройте demo, нажмите карандаш рядом с датой. В модалке есть название задания, текущая дата и поле новой даты.
4. С той же датой и с пустым полем «Сохранить» выключена. «Отмена» не меняет задание. Пока модалка открыта, переключение real/demo заблокировано.
5. Выберите новую дату, сохраните. Покажите уведомление, обновлённый срок, сводку и историю MCP-вызовов. Перезагрузите страницу: срок останется до завершения этого демо-сервера.
6. Перенесите срок активной задачи на сегодня, затем в прошлое. Сегодня — не просрочено; прошлое — просрочено. У выполненной задачи прошлая дата не меняет статус и не делает её просроченной.
7. Покажите [браузерный отчёт](frameworks/evidence/integrated/browser.json) и [backend-проверки](frameworks/evidence/integrated/backend-contract.json). В браузерном тесте 502 имитируется отдельно; после снятия имитации повтор успешно сохраняется через настоящий сервер.

Ошибка при выключенном HTTP-сервере — сетевая. Ответ 502 означает, что HTTP-мост работает, но не смог выполнить MCP-вызов. Пустой ввод проще показать через UI, неправильную календарную дату и неизвестный ID — по реальному HTTP/MCP отчёту.

Объясните авторство: два чата GPT‑5 подготовили процесс; после исчерпания квоты реализацию и завершение проверок выполнил Codex с разрешения пользователя. Не обещайте вызов модели на защите без доступной квоты.
