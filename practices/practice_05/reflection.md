Ограничения
- Редакция по regex не покрывает все возможные секреты.
- Нет auth/ratelimit; модель отвечает на английском/русском — UI отображает как есть.
- Локальный demo без конфигурации CI; concurrency браузерных проверок отдельным чатом.

Что исправили по ревью и проверкам
- Строгая валидация ответа провайдера (риски/проверки, типы).
- Точный Origin с портом, Content-Type/Length проверки.
- ThreadingHTTPServer с daemon_threads для доступности preview/provider во время review; корректная обработка BrokenPipe.
 - Сервис не выдаёт ключ браузеру и не логирует его. При поиске конфигурации агент случайно вывел .env в журнал OpenCode; пользователю рекомендовано перевыпустить ключ.
