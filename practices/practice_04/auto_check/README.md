# Practice 04 Auto Check — описание

Skill автоматизирует запуск проверок для практики 4. Загружаемые инструкции —
`SKILL.md`; источник `./practices/practice_04` указан в `opencode.json`, ID в OpenCode — `auto_check`.
`skill.json` сохранён как прежнее описание команд, а не как механизм загрузки.

- Инструкция в SKILL.md направляет агента запускать `practices/practice_04/runner.sh` после правок и читать результаты из логов.
- Runner через реальные MCP-процессы проверяет трекер и мост дашборда и сохраняет diff. При наличии npm-зависимостей он также собирает React.
- Это процедурный skill: сам по себе Markdown не является файловым наблюдателем. Автозапуск после правки выполняет агент согласно правилам, а после коммита — Git hook.

Как запустить:

- В OpenCode: попросите загрузить skill `auto_check` и выполнить его инструкции.
- Вручную: `make p4-run`, `make p4-study-demo`.

Проверенный результат — файлы логов:

- `logs/runner.log` — общий ход проверки;
- `logs/study_tracker_demo.json` — успешные и ошибочные MCP-вызовы трекера.
- `logs/changes.diff` — снимок текущих незакоммиченных изменений, включая новые исходники и работу, выполненную до этой сессии; генерируемые логи исключены.
