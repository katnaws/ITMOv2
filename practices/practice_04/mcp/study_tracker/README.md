# Study Tracker MCP

Локальный учебный трекер: Python 3.9+ со стандартной библиотекой и данными SQLite.
Сервер поддерживает MCP stdio версии 2025-06-18: `initialize`, уведомление
`notifications/initialized`, `tools/list`, `tools/call`, `ping`.
Он остаётся запущенным для последовательных вызовов; stdout содержит только JSON-RPC.

| Инструмент | Аргументы | Результат |
|---|---|---|
| `add_task` | title, course, deadline (YYYY-MM-DD) | Новое задание с ID |
| `list_tasks` | course и status (необязательно) | Задания по дедлайну |
| `update_task_status` | task_id, status | Обновлённое задание |
| `study_dashboard` | as_of (необязательно) | Прогресс, просрочки, сроки на неделю, ближайшая задача |

Статусы: `todo`, `in_progress`, `done`. Дедлайн — включительно: просрочка
наступает на следующий день по Москве. Выполненные задания не попадают в просрочки.
Повторное добавление создаёт отдельное задание. `next_task` — незавершённое
задание с самым ранним дедлайном, включая просроченные.

## Запуск из корня репозитория

```sh
opencode mcp list
make p4-study-demo
make p4-run
```

Демо создаёт временную базу и проверяет все четыре инструмента, перезапуск
сервера, расчёт дат, фильтры и ошибки. Пользовательская база находится в
`practices/practice_04/mcp/study_tracker/data/tasks.sqlite3`, исключена из Git и не заполняется демо.
Переменная `STUDY_TRACKER_DB` позволяет выбрать другую базу.

Настоящий вызов через отдельный процесс сервера (изменит пользовательскую базу):

```sh
python3 practices/practice_04/mcp/client.py practices/practice_04/mcp/study_tracker/server.py add_task '{"title":"Подготовить защиту","course":"Технологии ИИ","deadline":"2026-10-15"}'
python3 practices/practice_04/mcp/client.py practices/practice_04/mcp/study_tracker/server.py study_dashboard '{}'
```

## Демонстрация агенту

В новом чате OpenCode из корня репозитория:

> Прочитай AGENTS.md и загрузи skill auto_check. Через MCP study_tracker
> добавь задание «Подготовить защиту практики 4», курс «Технологии ИИ»,
> дедлайн 2026-10-15. Переведи его в in_progress и покажи сводку прогресса.

Затем:

> Попробуй добавить задание с датой 2026-02-30. Покажи ошибку MCP и проверь,
> что задание не появилось в списке.

Сохрани вывод tool calls или скриншот для подтверждения работы именно агента.
Локальное интеграционное демо подтверждает протокол, но не вызов моделью.

Ограничения: только локальные данные, без уведомлений и календарной синхронизации;
поиск курса по точному названию; прогресс — доля выполненных заданий без весов.
Транспорт предназначен для небольшой учебной демонстрации и не реализует
все необязательные возможности MCP (ресурсы, промпты, отмену, потоковый прогресс).

Документация: [MCP tools](https://modelcontextprotocol.io/specification/2025-06-18/server/tools),
[OpenCode MCP](https://opencode.ai/v2/docs/mcp-servers),
[OpenCode skills](https://opencode.ai/v2/docs/skills/).
