# AGENTS.md — правила и среда для практики 4

Этот файл описывает правила для рабочего агента OpenCode (Build) и то, как он применяет skill и MCP при выполнении задач практики 4.

## Общие правила работы агента

- Работай в режиме Build, сохраняй изменения патчами (diff) и веди журналы.
- После каждого изменения файлов в папке `practices/practice_04/` запускай автоматическую проверку (runner) и прикладывай краткий вывод проверки в ответ.
- Загружай skill `practice_04/auto_check` и используй его runner для проверки. Skill описан в `practices/practice_04/auto_check/`.
- Любая команда, требующая shell, должна запускаться из корня репозитория; пути в сообщениях — абсолютные или с корня.

## Подключения и их назначение

- Skill `practice_04/auto_check` — автоматизирует запуск проверки после правок: собирает изменённые файлы, вызывает runner и добавляет резюме результата в логи.
- MCP `study_tracker` — хранит учебные задания в SQLite, показывает дедлайны и прогресс. Инструменты: `add_task`, `list_tasks`, `update_task_status`, `study_dashboard`. Реальные задания добавляй только по запросу пользователя; проверки выполняй на временной базе.
- Git hook `post-commit` — обеспечивает автоматический запуск runner после фиксации изменений, даже без участия агента (доп. демонстрация автоматики).

## Как агент применяет среду

1. Читает этот файл и skill `practices/practice_04/auto_check/SKILL.md` (в OpenCode ID `auto_check`, источник `./practices/practice_04` в конфигурации).
2. При правке в `practices/practice_04/` вызывает runner: `bash practices/practice_04/runner.sh`.
3. При ошибке runner — возвращает краткое описание ошибки и рекомендации.

## Команды для вручнуюго запуска (для ревью)

- Проверка: `bash practices/practice_04/runner.sh`
- Трекер: `make p4-study-demo` — MCP-вызовы на временной базе, включая ошибочные входы.
- Подключение OpenCode: `opencode mcp list`.
